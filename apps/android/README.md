# Cascade — Android

Native Kotlin + Jetpack Compose shell over `cascade-core` via UniFFI.

End users: install from
[cascade.stephens.page/apps](https://cascade.stephens.page/apps)
(sideload APK). This README is for building from source.

```bash
./gradlew :app:assembleDebug
```

Needs the Android SDK + NDK. Open `apps/android` in Android Studio, or run
the Gradle task above.
