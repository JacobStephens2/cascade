Get the app

Cascade for Windows

Windows 10 (2004+) / 11 · 64-bit · v0.2.1

A WinUI 3 / .NET build with System Media Transport Controls (lock-screen and media-key support) and sleep-prevention during long focus sessions. Self-contained — no .NET install required.

Download for Windows

Extract the .zip and run win-x64\Cascade.exe. This build isn’t code-signed yet, so Windows SmartScreen may warn on first launch — choose More info → Run anyway.

Cascade for macOS

macOS 14+ · Apple Silicon & Intel · v0.2.0

A SwiftUI menu-bar app that lives in your status bar, with Now Playing integration and sleep-prevention during long focus sessions.

Download for macOS

Developer ID signed and notarized by Apple — open the disk image and drag Cascade to Applications. No Gatekeeper workaround.

Cascade for Android

Android 8.0+ · Universal APK · v0.2.5

A Kotlin + Jetpack Compose app with Media3 background playback, so the waterfall keeps going with the screen off — plus lock-screen and notification controls.

Download for Android

The APK is a sideload build, not a Play Store listing. You’ll need to allow installs from your browser or file manager when prompted. Google Play Protect may also warn — choose Install anyway.

Cascade for iPhone & iPad

iOS 16+ · TestFlight beta

A SwiftUI app with lock-screen and Control Center playback, plus background audio with the screen off. The Apple Watch app comes with this install — after Cascade is on the iPhone, enable it in the Watch app under Available Apps.

Join the TestFlight beta

This is a beta, not an App Store listing. Install TestFlight on your iPhone or iPad, then open the link.
